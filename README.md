# Sonic Mastering EQ — Releases

Builds of **Sonic Mastering EQ**, Sonic Studio's six-band mastering EQ plug-in
for macOS (AU, VST3 and AAX). This repository distributes the plug-in; it is
not where Sonic Mastering EQ is developed and contains no source code.

## Downloading

Open [Releases](../../releases) and download the `Sonic Mastering EQ <version>.zip`
asset from the newest entry. That zip contains a signed, notarized disk image
with the installer, an uninstaller and the release notes.

The plug-in requires a **Sonic Studio Mastering EQ** iLok licence.
soundBlade 3.0 users don't need this download: soundBlade's own disk image
includes Sonic Mastering EQ, authorized by the soundBlade licence.

Release notes for every version: [RELEASE-NOTES.md](RELEASE-NOTES.md), or as a
web page at https://streamsoft-inc.github.io/SonicMasteringEQ-releases/

## About the "Source code" downloads

Every release also lists **Source code (zip)** and **Source code (tar.gz)**.
Those are generated automatically by GitHub for the release's tag and cannot be
turned off. They contain only this README and the release notes.

**They are not Sonic Mastering EQ's source, and they are not the plug-in.** If
you are looking for the build, use the `Sonic Mastering EQ <version>.zip` asset
above.
